?Claude Codeって何？

Claude Code（クロード・コード）は、Anthropic社が作ったAIアシスタントです。あなたのパソコン上で動き、お願いした作業を実際に手を動かして進めてくれます。「ファイルを整理して」「このデータを集計して」「簡単なメモアプリを作って」といった依頼を、日本語の会話だけで頼めます。

ふつうのチャット型AIとの一番の違いは、ただ答えるだけでなく、実際にファイルを作ったり書き換えたりできる点です。しかも作業の前に「こう変更していいですか？」と必ず確認してくれるので、勝手に何かが壊れる心配は少なくなっています。

できること（一例）あなたが打つのはこれだけ
フォルダ内のファイルをルールで並べ替え・改名「このフォルダの写真を撮影日ごとにフォルダ分けして」
CSVやExcelの集計・グラフ化「売上データを月別に合計して、棒グラフにして」
定型作業を自動化する小さなプログラム作り「毎朝この作業をやってくれる仕組みを作って」
メモ帳・電卓などのミニアプリやWebページ「シンプルな買い物リストのアプリを作って」
わからないことの相談・下調べ「このエラーの意味を教えて」「◯◯のやり方を調べて」

② Windowsパソコン

Windows 10（1809以降）または Windows 11、メモリ4GB以上、インターネット接続があればOKです。今お使いのパソコンでほぼ問題なく動きます。

22つの始め方 ― まず「かんたんな方」でOK

Claude Codeには入り口が2種類あります。未経験の方は、まずA（デスクトップアプリ）から始めるのがいちばんラクです。慣れてきたらB（ターミナル）も試す、という順番で構いません。

  • 次の章のインストール手順で、コマンドを1行コピペするだけで入ります。

3インストール手順（Windows）

A. デスクトップアプリ版を入れる（かんたん）

  1. ダウンロード

    claude.com/download を開き、Windows版をダウンロードします。

  2. インストール

    ダウンロードしたファイルをダブルクリックし、画面の案内どおり「次へ」を押していくだけです。

  3. ログイン

    アプリを起動し、①で作ったProなどの有料プランのアカウントでログインします。これで準備完了です。

B. ターミナル版を入れる（コマンド1行）

  1. PowerShellを開く

    キーボードの Windows キーを押して PowerShell と入力し、出てきた「Windows PowerShell」をクリックして開きます。黒っぽい（または紺色の）画面が出ればOKです。

    画面の見分け方 行の先頭が PS C:\ で始まっていれば PowerShell です。PS が無く C:\ だけなら「コマンドプロンプト（CMD）」で、その場合は下のCMD用コマンドを使います。

  2. インストールコマンドを貼り付けて実行

    下の1行をコピーし、PowerShellの画面をクリックしてから貼り付け（Ctrl+V）、Enter を押します。数十秒〜数分待つと完了します。

    irm https://claude.ai/install.ps1 | iex

    ※もし画面が C:\（CMD）だった場合は、代わりにこちら：

    curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

  3. ちゃんと入ったか確認

    続けて次を打って Enter。2.1.xxx (Claude Code) のようにバージョン番号が出れば成功です。

    claude --version
    「認識されません」と出たら いったんPowerShellを閉じて開き直してから、もう一度 claude --version を試してください。それでもダメなときは、後述のトラブル対処へ。

  4. （推奨）Git for Windows も入れる

    必須ではありませんが、Git for Windows を入れておくとClaude Codeがより多くの作業をこなせるようになります。案内どおり「Next」を押し続けるだけで入ります。あとからでも大丈夫です。

  5. 起動してログイン

    作業したいフォルダで claude と打って Enter。初回はログインを求められるので、ブラウザが開いたら有料プランのアカウントで許可します。次からはログイン不要です。

    claude
「フォルダで開く」ってどういうこと？ Claude Codeは「今いるフォルダ」を作業場所にします。例えばデスクトップの「練習」フォルダで作業したいなら、そのフォルダを開いた状態で始めるのがコツ。ターミナル版なら cd という命令で移動しますが、最初はアプリ版のフォルダ選択を使うのがかんたんです。

4Lv.1 はじめての会話をしてみる

準備ができたら、まずは気軽に話しかけてみましょう。難しいことは考えず、日本語でそのまま入力して Enter を押すだけです。

Claude Codeで何ができるのか、初心者向けに教えて
このフォルダには何が入っている？わかりやすく説明して
「hello.txt」というファイルを作って、中に自己紹介文を書いて

3つめのように「ファイルを作って」と頼むと、Claudeは作る内容を見せて「これでいいですか？」と確認してきます。よければ承認、直したければ「もっと短くして」などと返せば作り直してくれます。この会話→確認→承認の流れが、Claude Codeの基本リズムです。

最初の練習におすすめ デスクトップに「claude練習」など空のフォルダを1つ作り、その中で色々試してみましょう。空フォルダなら失敗しても何も壊れないので、安心してあれこれ頼めます。

5Lv.2 基本操作を覚える

会話に慣れたら、便利な操作をいくつか覚えましょう。全部いっぺんに覚える必要はなく、「へぇ、そんなのがあるんだ」くらいでOKです。

スラッシュコマンド（/ で始まる命令）

入力欄で / を打つと、使える命令の一覧が出ます。よく使うのはこれくらい：

コマンド何をする？
/help使い方・コマンド一覧を表示する
/clear会話をリセットして、まっさらな状態に戻す（話題を変えるとき便利）
/loginログインし直す・アカウントを切り替える
/exitClaude Codeを終了する

覚えておくと便利なキー操作

  • ↑（上矢印）… 前に打った内容を呼び出す
  • Tab … コマンドやファイル名を自動補完する
  • Shift+Tab … 許可モードを切り替える（下記参照）

許可モードを知っておく（安心のカギ）

Claude Codeには「どこまで自動でやらせるか」の設定があり、Shift+Tab で切り替えられます。未経験のうちはいちばん慎重なモードのままで大丈夫です。

モードふるまい初心者は
ふつう（既定）変更のたびに「していい？」と確認する◎ まずはこれ
編集を自動承認ファイル編集をいちいち聞かずに進める△ 慣れてから
計画モード実際には変更せず、やることの計画だけ提案する◯ 下調べに便利
最初は「確認あり」で使うのが正解 毎回確認が入るのは少し手間に感じるかもしれませんが、これが意図しない変更を防ぐ安全ネットです。中身をよく読んでから承認する習慣をつけましょう。

6Lv.3 上手な頼み方のコツ

Claude Codeを使いこなせるかどうかは、プログラミング知識よりも「頼み方（伝え方）」で決まります。ここが未経験者にとっていちばん大事な"技術"です。コツは4つ。

コツ①　具体的に伝える

あいまいな指示より、状況・目的まで書いたほうが、ずっと良い結果になります。

△ ざっくり◎ 具体的
「整理して」「このフォルダのPDFを、ファイル名の日付ごとに月別フォルダへ移動して」
「表を作って」「名前・電話・メールの3列の表を作り、Excelで開ける形式で保存して」

コツ②　大きな作業は手順に分ける

やりたいことが大きいときは、番号付きで段階的に頼むと迷子になりません。

1. まずこのフォルダにどんなファイルがあるか一覧にして
2. そのうち画像ファイルだけを「画像」フォルダにまとめて
3. 残ったファイルの一覧をテキストに書き出して

コツ③　まず「調べて・計画して」から動かす

いきなり作らせず、先に状況を把握させると精度が上がります。「まず〜を確認してから、どうするか教えて」と頼むのがコツ。

このExcelファイルの中身をまず確認して、どんな集計ができそうか提案して。作業はまだしないで

コツ④　遠慮せず会話を続ける

結果が思ったのと違っても、やり直しは一言でOK。同僚に話しかけるように、気軽に修正を頼みましょう。「もっと簡単にして」「色を青にして」「さっきのを元に戻して」など、何度でも直せます。

わからない言葉が出てきたら Claudeの返事に専門用語が出てきたら、そのまま「今の"◯◯"って何？初心者にもわかるように説明して」と聞けばOK。Claude Code自体が最高の先生になります。

!安全に使うための注意

  • 大事なファイルはコピーで試す。 慣れるまでは、元データではなく複製フォルダで作業しましょう。
  • 変更内容は読んでから承認する。 「確認しますか？」で中身にざっと目を通す習慣を。よくわからなければ「これは何をする変更？」と聞けばOK。
  • パスワードや個人情報は不用意に貼らない。 必要な場合を除き、機密情報は入力を控えめに。
  • ネットからのコマンドを鵜呑みにしない。 知らないサイトに書かれたコマンドをそのまま実行するのは避け、意味を尋ねてから。
  • 「元に戻して」が使える。 直前の変更なら会話で戻せることが多いです。Git for Windowsを入れておくと、変更履歴の管理も頼めてさらに安心です。

症状対処

インストールでエラーが出るPowerShellとCMDを取り違えていないか確認（先頭が PS かどうか）。正しい方のコマンドで再実行。

いちばん確実な相談先 困ったら、Claude Codeにそのまま日本語で症状を伝えるのが最短です。「〜というエラーが出た。どうすればいい？」で、解決方法を一緒に探してくれます。公式ドキュメントは code.claude.com/docs（英語）。

Qよくある質問

本当にプログラミングの知識はいらない？

最初は不要です。日本語で頼めば動きます。ただ、使ううちに「これは何をしているんだろう？」と興味が出てきたら、その都度Claude Codeに解説してもらうと、自然と少しずつ理解が深まります。知識ゼロで始めて、遊びながら覚えていくのが理想的です。

間違えて大事なファイルを壊さない？

既定では変更のたびに確認が入るので、いきなり壊れることは基本ありません。加えて「大事なデータはコピーで試す」を守れば安心です。Git for Windowsを入れておくと、変更を記録して元に戻す作業も頼めます。

アプリ版とターミナル版、結局どっちを使えばいい？

どちらでも同じことができます。とっつきやすさ重視ならアプリ版、ネットの解説記事や動画を参考にしたいならターミナル版が便利（世の中の情報はターミナル版が多いため）。両方入れておいて、気分で使い分けるのもアリです。

英語ができないと使えない？

いいえ。日本語でそのまま会話できます。返事も日本語でお願いすれば日本語で返ってきます。

料金はどのくらいかかる？使いすぎない？

個人ならProプラン（月20ドル前後）の定額で始められ、その範囲内でたっぷり使えます。使用量に上限があり、超えそうなときは知らせてくれます。最新の料金は公式ページで確認を。

Macでも同じようにできる？

できます。インストールのコマンドが違うだけで、使い方（Lv.1以降）はまったく同じです。Mac版が必要になったら気軽に聞いてください。
