# 仕様：共通機能と展示の型

数値はすべて試作（`reference/kantansui_hall_v2.html`）の現在値。変更するときはオーナーに確認する。

## 1. ホールの構成

ホールは1ページ。上から順に次の要素が並ぶ。

1. トップバー（固定）：ランク表示（XP）、コイン、効果音の切り替え、スタンプの進み具合
2. 入口：ホール名の大見出しと入館券。券の半券を「もぎる」と館内図へスクロールする
3. 館内図：臓器キャラのSVG。臓器をタップするとその展示室（ウィング）へ移動。下に全展示のショートカット（クリア済みは緑）
4. ウィング（臓器ごと）：展示が1〜4点
5. ごほうびコーナー：ガチャ
6. 収蔵庫：まちがえた問題の保管室
7. フッター：スタンプカードを開くボタン、「未レビュー」の注記

## 2. 共通機能

### コインとXP
- 正解でコインがもらえる。もらったコインは同額がXPにも加算される（XPは減らない）。
- 付与時にコイン表示が跳ね、押した要素の上に「+n」が浮かぶ。
- スタンプ獲得でXP +50、ガチャの新種でXP +10、図鑑コンプリートでXP +100。

### ランク
XPの閾値：0 見習い学芸員、150 学芸員、400 主任学芸員、800 副館長、1300 館長。昇進時にトースト、ファンファーレ、紙吹雪。

### スタンプ
- 展示ごとに1つ（ガチャと収蔵庫は対象外）。条件は各展示の項を参照。
- 全部そろうと、スタンプカードが修了証（名前入力欄つき）に変わる。

### 収蔵庫（要復習）
- 展示でまちがえると、その問題が `{id, src, q, opts, ans}` の形で収蔵庫に保管される（同じidは重複しない）。
- 収蔵庫では選択式で再挑戦でき、正解すると「退館」して消え、5コイン。

### カンペ
- 基準表を見たい人だけが開ける仕組み。説明文の下に点線の「カンペを見る」ボタンを置き、押すとダイアログで基準表を表示する。
- 1ラウンド（1問、1患者）の間に一度も開かずに正解すると「ノーカンペ +5」。開いても減点はしない。
- 現在の対象：HBV、肝癌すごろく、胆管炎ER、急性膵炎。

### ガチャ（ごほうび）
- 1回30コイン、最初の1回は無料。
- ダブったら10コイン返却。
- 天井：ダブりが4回続いたら、次は未入手から確定。ボタンの下に「あと○回以内に新種確定」と表示する。
- 確率は「普通に館長まで遊べばコンプリートできる」ことを基準に決める。試作の設定でコンプリートまで平均約20回、9割の人が25回以内（シミュレーションで確認済み）。旧設定（最レア2%）では平均71回かかり、オーナーから「コンプできない」と指摘があった。新しいホールでもシミュレーションで確認すること。

### 保存
- コイン・XP・ランクは館全体で共有する（キー `diseaseMuseum.museum.v3`）。スタンプ・ガチャ図鑑・収蔵庫・進み具合はホールごと（`diseaseMuseum.hall.<id>.v3`）。試作（`diseaseMuseum.hall03.v2`）のデータは引き継がない。
- スタンプカードの「このホールを最初から」はそのホールの記録だけを消す。館の入口の「館全体のデータを消す」はすべて消す。
- 設定（音のオンオフ）は保存しない。

### 演出
- 正解：短い上昇音、正解の選択肢が緑に。
- 不正解：低いブザー、選んだものがピンクで揺れる。正解も同時に表示する。
- 大きな達成：ファンファーレと紙吹雪。

## 3. 展示の型（10種）

各型の「データ」は `docs/DATA_SCHEMA.md` の型名と対応する。

### 3.1 診断ラボ（DiagnosisLab）　例：黄疸診断ラボ
- 目的：検査の選び方そのものを学ぶ。「何を否定するための検査か」。
- 流れ：患者カード（年齢・性別・一言の病歴）→ 予算内で検査を選ぶ（結果が伝票に1行ずつ出る。異常値は赤）→ 診断を選ぶ。
- 数値：予算7、検査は7種（コスト1〜3）、鑑別6択。正解で 20＋残り予算×3 コイン。
- 回答後：解説と「理想の流れ」ステッパー。問診 → 検査1 → 検査2…と進むごとに、鑑別6つの確率バーが変化し、「否定：〜」「上昇：〜」が色分けで出る。プレイヤーの検査のうち理想の流れにないものは「今回は決め手にならず」と表示し、コストを比べる。確率は手で決めたイメージ値で、画面にもそう明記する。
- スタンプ：通算4人正解。

### 3.2 病態シミュレーター（PathoSim）　例：門脈の渋滞マップ
- 目的：病態生理を、動く図で因果として理解する。
- 前半：スライダー（HVPG 3〜22 mmHg）を動かすと、図の側副路が閾値ごとに現れ、脾臓がふくらみ、血流アニメが遅くなる。閾値ごとの説明文が変わる。
- 後半：治療ミッション5問（場面文 → 治療の選択肢5つ）。複数正解あり（alt）。正解15コイン。
- スタンプ：ミッション5種すべて正解（通算）。

### 3.3 解読パズル（DecodePuzzle）　例：HBVマーカー解読
- 目的：検査パターンの読み取り。
- 解読モード：ランプ（陽性・陰性）の組み合わせを見て状態を6択で答える。1周6問、正解12コイン。スタンプは1周で5問以上。
- 逆モード：お題の状態に合わせて、自分でランプを点ける（3個）。正解10コイン。

### 3.4 すごろく（AlgorithmBoard）　例：肝細胞癌 治療すごろく
- 目的：治療アルゴリズムの分岐順を体で覚える。
- 横に並んだマス（分岐ノード）の上をコマが進む。患者カードの情報から、各マスの分かれ道を選ぶ。まちがえると1マス戻る。通らないマスは打ち消し線で薄く表示。
- ゴールで治療を選ぶ（複数正解あり）。正解25コイン。
- スタンプ：通算4人ゴール。

### 3.5 ER（EmergencySim）　例：胆管炎ER
- モニターは波形を緑のままにし、基準範囲（データの `normalRanges`、演出用のイメージ値）の外の値だけを赤く点滅させる。心電図の速さは HR に合わせる。まちがえると経過時間の札が赤くなる（Phase 2 で変更、オーナー了承）。
- 目的：重症度判定から初期対応までを時間の圧力つきで。
- 心電図モニター（BP、HR、SpO₂、体温、意識）と経過時間。
- STEP 1：重症度を選ぶ（正解15コイン）。STEP 2：必要な指示を複数選択し、処置のタイミングを1つ選ぶ（正解30コイン）。まちがえるたびに30分経過し、モニターが赤くなる。成功するとバイタルが落ち着く。
- スタンプ：通算3人成功。

### 3.6 タイムアタック（ScoreAttack）　例：急性膵炎 予後因子
- 目的：スコアリング項目を素早く拾う力。
- 検査値タイルを毎回ランダム生成し、陽性の項目をタップしてから重症度を判定。制限時間45秒（残り10秒で警告音）。
- 判定：重症度が正しく、拾いまちがいが1つ以内なら正解。20＋残り秒数÷3 コイン。
- 回答後、タイルを色分け（正しく拾った＝緑、見落とし＝ピンク、余分＝打ち消し線）。
- 同じ展示に「画像スコア」種目を併設できる（造影CT Gradeの模式図から2つの点数を読む。正解20コイン）。スタンプはそれぞれ2回正解。

### 3.7 VS対決（VersusQuiz）
- 目的：似た疾患の鑑別点。
- 左右にファイターカード（名前と特徴3つ）。中央にヒントが1枚ずつ出るので、どちらのものか答える。1試合6問、試合は複数。
- 連続正解でコンボ表示。正解 5＋min(コンボ,5)×2 コイン。正解した側のカードが跳ねる。
- スタンプ：1試合で5問以上。

### 3.8 神経衰弱（MemoryMatch）
- 目的：マーカー・抗体と疾患の対応。
- 8ペア16枚。マーカー側のカードは黄色。ペア成立4コイン、20手以内のクリアで30コインのボーナス。
- スタンプ：クリア。

### 3.9 身体所見さがし（BodyHotspot）　※ver.1で使用、ver.2では門脈に置き換え
- 全身イラストの光る点をタップすると所見カードが出る。全部見つけたらクリア。新しいホールで身体所見を扱うときに使う。

### 3.10 ガチャ（Gacha）
- 上記「共通機能」を参照。景品はそのホールの「小ネタ」（胆石の種類など）で、レア度は★1〜4。

## 4. 共通ゲームとホール専用のゲーム（type: "Custom"）

### 共通ゲーム（src/engine/games/、どのホールからも kind の名前で使える）
- reveal（影絵当て）：模式図がぼかしから少しずつくっきりする早押し。20→4コイン。通算 stampAt 枚の一発正解でスタンプ。
- clueRace（早押し問診）：カードを1枚ずつめくる早押し。腹部9区分の「痛む場所」カードあり。
- depth（深達度タップ）：断面図の層をタップ（10）→治療（15）。lesionLabel・topLabel で病変と図の説明を変えられ、hideLesion で病変を描かずに所見だけで当てさせる（熱傷）。
- grid（分類マス）：行×列の表のどのマスかをタップ（治療があれば10、なければ15）→治療（15、任意）。心不全の4分類、酸塩基平衡など。
- order（並べ替え）：カードを正しい順にタップ。ミス0回20コイン、1回ごとに−5（最低5）。ノーミスを通算 stampAt 問でスタンプ。
- tapMap（部位タップ）：データで渡した図の領域をタップ（15）→続けて質問（10、任意）。答えが複数なら全部選んで決定。
- scenario（シナリオ判断）：状況とバイタルを見て次の一手を選ぶ。1手10、ミス maxMistakes 回までならクリア（+20）。
- abg（血液ガス道場）：pH → 一次性障害 → 代償 → AG → 原因の順に答える。代償の予測式は abg.consts.ts で計算。
- microscope（顕微鏡で探せ）：視野の中の目標を全部タップ（12、まちがい1回ごとに−3、最低2）→ 意味を答える（12）。見つけ方（まちがい1回まで）と判断の両方が正解でカウント。尿沈渣、末梢血、グラム染色など。
- axis（ホルモン軸）：視床下部→下垂体→標的臓器のホルモンを ↑・→・↓ で予想（全部正解15）→ 原因（10）。
- visualField（視野と病変）：病変の場所から視野の絵を自動で描き、上から見た視覚路の図で病変をタップ（15）→ 質問（10、任意）。
- gcs（GCS採点）：患者の様子から E・V・M を付ける（全部正解15）→ 質問（10、任意）。
- criteria（診断基準チェック）：所見の中から基準に入るものを全部チェック（全部正しく15）→ 判断（10）。川崎病の主要症状、熱性けいれんの複雑型など。
- triage（トリアージ）：傷病者を1人ずつSTART法で色分け。1人5、roundSize 人中 passScore 人以上で合格（+15）。色は triage.consts.ts で計算。


### ホール専用のゲーム

型の一覧に合わせてゲームを考えなくてよいように、ホール専用のゲームを作れる。`src/halls/<hall>/exhibits/` に `<kind>.ts`（描画）、`<kind>.schema.ts`（zodでデータの形）、`<kind>.css` を置き、`exhibits/index.ts` と `exhibits/schemas.ts` に登録する。コイン・スタンプ・収蔵庫・カンペはほかの型と同じように使える。別のホールでも使うようになったら共通の型に格上げする。

### 消化管ホールのゲーム（Phase 2）
- 造影シルエット早押し（reveal）：模式図がぼかし5段階から少しずつくっきりする。当てたときの段階で 20→16→12→8→4 コイン。まちがえると選択肢が消えて1段見える。通算4枚を一発正解でスタンプ。
- 内視鏡ラン（endoscopy）：1回の検査で5つの病変（食道→胃→十二指腸の順）。正しい判断で10コイン、5つ中4つ以上でクリア（+20、スタンプ）。
- 深達度タップ（depth）：壁の断面で深達度をタップ（10）→治療を選ぶ（15）。両方正解を通算4症例でスタンプ。
- 切除範囲をなぞる（resection）：大腸の区間をタップで選び、選んだ組み合わせから術式名が決まる。正解20コイン。通算4人でスタンプ。
- 食中毒の犯人さがし（foodTimeline）：対数目盛のタイムラインで食事を選ぶ（10）→原因微生物（15）。回答後に正解の潜伏期を帯で表示。両方正解を通算4件でスタンプ。
- 早押し問診（clueRace）：カードを1枚ずつめくる。当てた枚数で 30→25→20…（最低5）。まちがえると1枚めくれる。3枚以内の一発正解を通算4人でスタンプ。1枚目に腹部9区分の「痛む場所」を出せる。

### 循環器ホールのゲーム（Phase 3）
心電図は `src/halls/junkanki/ecg/` で合成する（synth.ts が波形の計算、render.ts が方眼紙への描画）。
- 心電図道場（ecgDojo）：II誘導8秒の記録を読んで5択。1問10コイン、8問中7問で段位クリア。中級以上のクリアか模擬検定合格（10問中8問、8分、+50）でスタンプ。
- キャリパー計測（calipers）：2本の線をドラッグ（または◀▶）して測る。許容誤差内で10、判定で10。両方正解を通算4回でスタンプ。
- 12誘導読影（twelve）：ST上昇の誘導を全部選ぶ（15）→部位と責任血管（15）。所見当てモードは5択で15。通算5回の正解でスタンプ。
- 電気軸ダーツ（axisDarts）：六軸図をタップ。誤差15°以内20、30°以内12、45°以内6。分類で10。30°以内を通算3回でスタンプ。
- 心音オーケストラ（heartSounds）：病名15、聴診部位10。両方正解を通算4回でスタンプ。
- コードブルー（codeBlue）：1手10コイン、ミス1回までならクリア（+20）。通算2シナリオでスタンプ。
- 心不全の4分類：共通ゲーム grid を使う。

### Phase 4 のホール専用ゲーム
- 糖負荷曲線を読め（内分泌、ogtt）：75g OGTT のグラフから区分を判定（12）→ 診断・病態（12）。区分は値から計算し、データの answer と一致しなければ検証で失敗。
- 輸血バッグを選べ（血液、transfusion）：受血者の血液型と製剤から、入れても溶血しないバッグを全部選ぶ（20）。正解はルール（transfusion.consts.ts）から計算。
- 抗核抗体の光り方（免疫、ana）：染色型から蛍光の視野を自動で描き、型を答える（12）→ 抗体・疾患（12）。
- 抗菌薬スペクトラム（感染症、spectrum）：薬のカードを見て効く菌を全部選ぶ。まちがい0で20、1つで10（合格）、2つ以上は不合格。
- CTGを読め（産科・婦人科、ctg）：パラメータから10分間の胎児心拍数と子宮収縮を合成。一過性徐脈の種類（12）→ 評価・対応（12）。
- 成長曲線を読め（小児、growth）・熱型表で当てろ（小児、feverChart）：グラフを描いて ① 読む（12）→ ② 原因・対応（12）。2段の流れは halls/shoni/exhibits/twoStep.ts。
- 問診チャット（精神、chat）：患者の言葉が吹き出しで1つずつ届き、症状の用語を4択で選ぶ（1つ6）→ 最後に診断（12）。用語のまちがい1つまでで診断も正解なら合格。
- ほくろのABCDE（皮膚、mole）：パラメータから色素斑を描き、ABCDEのサインを全部選ぶ（15）→ 対応（10）。
- 瞳孔ラボ（眼、pupil）：明るい部屋・暗い部屋・右眼に光・左眼に光・近見を切り替えて両眼の瞳孔を観察し、原因（12）→ 質問（12）。瞳孔径は病態から計算。
- オージオグラムを読め（耳鼻咽喉、audiogram）：気導・骨導の値から描き、型（12）→ 原因（12）。型は値から計算し、データの answer と一致しなければ検証で失敗。
- 神経根レベル（運動器、root）：根ごとの筋力低下・反射・感覚（図に色）を見せ、根（12）→ 質問（12）。所見は root.consts.ts の表から出す。
- トキシドロームを見抜け（救急・中毒、toxidrome）：顔（瞳孔の大きさ・皮膚の乾湿）とバイタルから症候群（12）→ 解毒薬・対応（12）。
- 輸液のゆくえ（麻酔・輸液、fluidSpace）：1 Lのうち血管内に残る量をスライダーで予想（±20%か±40 mLで15）→ 3区画への分布を表示 → 質問（10）。分布は製剤のNa濃度から計算。
- 輸液ポンプ計算（麻酔・輸液、infusionCalc）：維持輸液・滴下数・自由水欠乏・補正上限。答えとまちがいの選択肢はコードで計算（18）。
- Mallampatiを判定せよ（麻酔・輸液、mallampati）：クラスから口の中を描き、分類（12）→ 質問（12）。
- カプノグラムを読め（麻酔・輸液、capnogram）：パターンから24秒の波形を合成し、状態（12）→ 対応（12）。
- カットオフを動かせ（公衆衛生、cutoff）：2つの正規分布と有病率から、1万人あたりの2×2表と4指標をその場で計算。目標（ある指標を一定以上に保ち、別の指標を最大に）を最適値から3%以内で満たせば20 → 質問（10）。
- 2×2表を計算せよ（公衆衛生、epiCalc）：研究デザインに合う指標だけを出題（検証で確認）。答えとまちがいやすい計算をコードで出す（18）。

## 5. 新しい型を作るときの条件

- 1回の操作で判断が1つ必要になること（見るだけの展示は作らない）。
- 正解と不正解の両方に解説が付くこと。
- 不正解の問題を収蔵庫に送れる形（選択肢が2〜4個）に変換できること。
- スタンプ条件は3〜5回程度の成功で届くこと。
