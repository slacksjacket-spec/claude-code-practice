# 仕様：共通機能と展示の型

数値はすべて試作（`reference/kantansui_hall_v2.html`）の現在値。変更するときはオーナーに確認する。

## 1. ホールの構成

ホールは1ページ。上から順に次の要素が並ぶ。

1. トップバー（固定）：ランク表示（XP）、コイン、効果音の切り替え、スタンプの進み具合
2. 入口：ホール名の大見出しと入館券。券の半券を「もぎる」と館内図へスクロールする
3. 館内図：臓器キャラのSVG。臓器をタップするとその展示室（ウィング）へ移動。下に全展示のショートカット（クリア済みは緑）
4. ウィング（臓器ごと）：展示が1〜4点
5. ごほうびコーナー：ガチャ
6. 収蔵庫：まちがえた問題の保管室
7. フッター：スタンプカードを開くボタン、「未レビュー」の注記

## 2. 共通機能

### コインとXP
- 正解でコインがもらえる。もらったコインは同額がXPにも加算される（XPは減らない）。
- 付与時にコイン表示が跳ね、押した要素の上に「+n」が浮かぶ。
- スタンプ獲得でXP +50、ガチャの新種でXP +10、図鑑コンプリートでXP +100。

### ランク
XPの閾値：0 見習い学芸員、150 学芸員、400 主任学芸員、800 副館長、1300 館長。昇進時にトースト、ファンファーレ、紙吹雪。

### スタンプ
- 展示ごとに1つ（ガチャと収蔵庫は対象外）。条件は各展示の項を参照。
- 全部そろうと、スタンプカードが修了証（名前入力欄つき）に変わる。

### 収蔵庫（要復習）
- 展示でまちがえると、その問題が `{id, src, q, opts, ans}` の形で収蔵庫に保管される（同じidは重複しない）。
- 収蔵庫では選択式で再挑戦でき、正解すると「退館」して消え、5コイン。

### カンペ
- 基準表を見たい人だけが開ける仕組み。説明文の下に点線の「カンペを見る」ボタンを置き、押すとダイアログで基準表を表示する。
- 1ラウンド（1問、1患者）の間に一度も開かずに正解すると「ノーカンペ +5」。開いても減点はしない。
- 現在の対象：HBV、肝癌すごろく、胆管炎ER、急性膵炎。

### ガチャ（ごほうび）
- 1回30コイン、最初の1回は無料。
- ダブったら10コイン返却。
- 天井：ダブりが4回続いたら、次は未入手から確定。ボタンの下に「あと○回以内に新種確定」と表示する。
- 確率は「普通に館長まで遊べばコンプリートできる」ことを基準に決める。試作の設定でコンプリートまで平均約20回、9割の人が25回以内（シミュレーションで確認済み）。旧設定（最レア2%）では平均71回かかり、オーナーから「コンプできない」と指摘があった。新しいホールでもシミュレーションで確認すること。

### 保存
- コイン・XP・ランクは館全体で共有する（キー `diseaseMuseum.museum.v3`）。スタンプ・ガチャ図鑑・収蔵庫・進み具合はホールごと（`diseaseMuseum.hall.<id>.v3`）。試作（`diseaseMuseum.hall03.v2`）のデータは引き継がない。
- スタンプカードの「このホールを最初から」はそのホールの記録だけを消す。館の入口の「館全体のデータを消す」はすべて消す。
- 設定（音のオンオフ）は保存しない。

### 演出
- 正解：短い上昇音、正解の選択肢が緑に。
- 不正解：低いブザー、選んだものがピンクで揺れる。正解も同時に表示する。
- 大きな達成：ファンファーレと紙吹雪。

## 3. 展示の型（10種）

各型の「データ」は `docs/DATA_SCHEMA.md` の型名と対応する。

### 3.1 診断ラボ（DiagnosisLab）　例：黄疸診断ラボ
- 目的：検査の選び方そのものを学ぶ。「何を否定するための検査か」。
- 流れ：患者カード（年齢・性別・一言の病歴）→ 予算内で検査を選ぶ（結果が伝票に1行ずつ出る。異常値は赤）→ 診断を選ぶ。
- 数値：予算7、検査は7種（コスト1〜3）、鑑別6択。正解で 20＋残り予算×3 コイン。
- 回答後：解説と「理想の流れ」ステッパー。問診 → 検査1 → 検査2…と進むごとに、鑑別6つの確率バーが変化し、「否定：〜」「上昇：〜」が色分けで出る。プレイヤーの検査のうち理想の流れにないものは「今回は決め手にならず」と表示し、コストを比べる。確率は手で決めたイメージ値で、画面にもそう明記する。
- スタンプ：通算4人正解。

### 3.2 病態シミュレーター（PathoSim）　例：門脈の渋滞マップ
- 目的：病態生理を、動く図で因果として理解する。
- 前半：スライダー（HVPG 3〜22 mmHg）を動かすと、図の側副路が閾値ごとに現れ、脾臓がふくらみ、血流アニメが遅くなる。閾値ごとの説明文が変わる。
- 後半：治療ミッション5問（場面文 → 治療の選択肢5つ）。複数正解あり（alt）。正解15コイン。
- スタンプ：ミッション5種すべて正解（通算）。

### 3.3 解読パズル（DecodePuzzle）　例：HBVマーカー解読
- 目的：検査パターンの読み取り。
- 解読モード：ランプ（陽性・陰性）の組み合わせを見て状態を6択で答える。1周6問、正解12コイン。スタンプは1周で5問以上。
- 逆モード：お題の状態に合わせて、自分でランプを点ける（3個）。正解10コイン。

### 3.4 すごろく（AlgorithmBoard）　例：肝細胞癌 治療すごろく
- 目的：治療アルゴリズムの分岐順を体で覚える。
- 横に並んだマス（分岐ノード）の上をコマが進む。患者カードの情報から、各マスの分かれ道を選ぶ。まちがえると1マス戻る。通らないマスは打ち消し線で薄く表示。
- ゴールで治療を選ぶ（複数正解あり）。正解25コイン。
- スタンプ：通算4人ゴール。

### 3.5 ER（EmergencySim）　例：胆管炎ER
- 目的：重症度判定から初期対応までを時間の圧力つきで。
- 心電図モニター（BP、HR、SpO₂、体温、意識）と経過時間。
- STEP 1：重症度を選ぶ（正解15コイン）。STEP 2：必要な指示を複数選択し、処置のタイミングを1つ選ぶ（正解30コイン）。まちがえるたびに30分経過し、モニターが赤くなる。成功するとバイタルが落ち着く。
- スタンプ：通算3人成功。

### 3.6 タイムアタック（ScoreAttack）　例：急性膵炎 予後因子
- 目的：スコアリング項目を素早く拾う力。
- 検査値タイルを毎回ランダム生成し、陽性の項目をタップしてから重症度を判定。制限時間45秒（残り10秒で警告音）。
- 判定：重症度が正しく、拾いまちがいが1つ以内なら正解。20＋残り秒数÷3 コイン。
- 回答後、タイルを色分け（正しく拾った＝緑、見落とし＝ピンク、余分＝打ち消し線）。
- 同じ展示に「画像スコア」種目を併設できる（造影CT Gradeの模式図から2つの点数を読む。正解20コイン）。スタンプはそれぞれ2回正解。

### 3.7 VS対決（VersusQuiz）
- 目的：似た疾患の鑑別点。
- 左右にファイターカード（名前と特徴3つ）。中央にヒントが1枚ずつ出るので、どちらのものか答える。1試合6問、試合は複数。
- 連続正解でコンボ表示。正解 5＋min(コンボ,5)×2 コイン。正解した側のカードが跳ねる。
- スタンプ：1試合で5問以上。

### 3.8 神経衰弱（MemoryMatch）
- 目的：マーカー・抗体と疾患の対応。
- 8ペア16枚。マーカー側のカードは黄色。ペア成立4コイン、20手以内のクリアで30コインのボーナス。
- スタンプ：クリア。

### 3.9 身体所見さがし（BodyHotspot）　※ver.1で使用、ver.2では門脈に置き換え
- 全身イラストの光る点をタップすると所見カードが出る。全部見つけたらクリア。新しいホールで身体所見を扱うときに使う。

### 3.10 ガチャ（Gacha）
- 上記「共通機能」を参照。景品はそのホールの「小ネタ」（胆石の種類など）で、レア度は★1〜4。

## 4. 新しい型を作るときの条件

- 1回の操作で判断が1つ必要になること（見るだけの展示は作らない）。
- 正解と不正解の両方に解説が付くこと。
- 不正解の問題を収蔵庫に送れる形（選択肢が2〜4個）に変換できること。
- スタンプ条件は3〜5回程度の成功で届くこと。
